# Google Search Console

Die [Google Search Console](https://search.google.com/search-console) ist
Googles Werkzeug für Suchanfragen, Indexierung und technische Hinweise zu
Websites.

**Sofern** für diese Website eine Property eingerichtet ist, können Sie sie
dort aufrufen:  
<https://search.google.com/search-console?resource_id=%%% setting host_base %%%>

Ein CMS-Login berechtigt **nicht** automatisch zum Zugriff. Zugang wird in der
Search Console unter **Einstellungen → Nutzer und Berechtigungen** von der
Website-Verwaltung vergeben.

Bitte wenden Sie sich für Zugang an die Website-Verwaltung unter
<%%% setting own_webmaster_mail %%%>.
